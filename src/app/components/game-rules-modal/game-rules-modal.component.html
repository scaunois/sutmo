Règle du jeu

Devinez le mot du jour en un nombre limité d'essais !

Il s'agit d'un nom commun, d'un verbe à l'infinitif ou d'un adjectif (masculin singulier). Pas de nom propre, pas de pluriel ou de forme conjuguée.
Pas de mot anglais ou autre langue étrangère, à moins que le mot soit couramment admis dans le langage français quotidien (exemple : weekend).

  • Vous avez un nombre limité d'essais.
  • Chaque tentative doit être un mot valide de notre dictionnaire (près de 150.000 mots).
  • Pour la saisie, les formes accordées (conjugaison, pluriel, féminin) sont autorisées.
  • Les lettres que vous avez trouvées seront pré-remplies pour vous faciliter la visualisation, mais vous pouvez les effacer
  • Si besoin, vous pouvez saisir un point ou un espace.

Une lettre entourée d'un carré rose foncé est bien placée.
Une lettre entourée d'un cercle rose clair est présente dans le mot, mais à une place différente.
Une lettre sans marquage (fond transparent) est absente du mot.
